# 游戏会话结束提示词

游戏会话与看门狗一对一强绑定并同步关闭。结束提示词完全由游戏会话管理器构造并投放；调用工具、断线监听、归档和清理路径只提供关闭类型与原因，不能自行拼装或重复投放。

同一个 `gameSessionId` 只会关闭、投放一次。自动重连期间游戏会话没有结束，不投放本提示词。

## 投放方式

- **立即投放并触发/插入一轮**：用户点击停止、助理主动退出或停止、被踢、连接异常、自动重连耗尽、看门狗任务被取消、切换服务器。使用插件提示行 `agent.steer`；不是用户发言。
- **延后到下一步，不主动唤醒**：会话归档、对话实例销毁、插件卸载或宿主关闭。提示行进入该会话的下一步队列。运行环境已无法接收消息时只记日志，不能承诺宿主退出后仍会即时生成。
- `steer` 失败时降级为延后投放；不降级成用户来源消息。

## 可用变量

- `${gameSessionId}`：刚刚结束的游戏会话 ID。
- `${server}`：服务器地址；拿不到时省略整行。
- `${reason}`：经过控制字符清理、凭据字段遮蔽和长度限制的结束原因。
- `${duration}`：游戏会话持续时间。
- `${attempts}`：自动重连次数，仅重连耗尽时使用。
- `${lastReconnectError}`：最后一次已知重连错误，仅存在时展示。

## 固定段

```text
【Minecraft 游戏会话已结束】
游戏会话 ID：${gameSessionId}
服务器：${server}
持续时间：${duration}
原因：${reason}

机器人连接、看门狗和本游戏会话的结构化事件队列均已关闭。建立新的游戏会话前，不要调用需要在线角色的观察或交互工具；仍可使用 mc_status、mc_connect 以及离线可用的配置或诊断工具。
```

服务器未知时不输出“服务器”一行。除“新连接替换旧连接”外，固定段后追加下列一种情形段；换服使用第 10 节的替代状态段。

## 1. 助理主动退出：`mc_disconnect`

```text
这是你主动执行的退出。停止仍以本局在线状态为前提的子代理或后台任务；不要自行重新连接。只有用户再次要求进入服务器时，才建立新的游戏会话。向用户简短确认已经退出。
```

## 2. 助理主动停止：`mc_stop`

```text
这是你主动停止的游戏会话。不要自行重新连接，也不要继续刚才的游戏任务。向用户简短确认游戏会话已经停止。
```

## 3. 用户点击“停止”

```text
这是用户主动停止了游戏会话。立即停止刚才的游戏任务，不要自行重新连接，也不要把这次停止当作需要排障的异常。向用户简短确认游戏会话已经停止。
```

## 4. 被服务器踢出

```text
你被服务器踢出了游戏。向用户说明服务器给出的原因；不要假装仍然在线，也不要自行反复重连。如果原因表明需要用户处理（白名单、封禁、登录冲突、认证失效等），明确告诉用户需要做什么；否则询问用户是否要重新连接。
```

## 5. 连接异常且不会自动重连

```text
Minecraft 连接已经异常结束，并且不会自动重连。向用户说明已知原因；不要继续执行游戏内操作。如果问题可能通过重新连接解决，询问用户是否要重新连接；如果需要用户处理，先说明处理办法。
```

## 6. 自动重连全部失败

```text
Minecraft 连接中断后，自动重连 ${attempts} 次仍然失败，原游戏会话已经结束。最后一次已知错误：${lastReconnectError}。不要继续执行游戏内操作，也不要再次自动发起连接；向用户说明情况并询问是否稍后手动重试。
```

次数或最后错误拿不到时，对应短语整体省略。

## 7. 会话被归档

```text
承载本次 Minecraft 游戏的对话会话正在归档，因此游戏连接和插件拥有的相关后台任务已经停止。不要重新连接，也不要继续刚才的游戏任务。
```

此情形延后投放，不重新唤醒正在归档的对话。

## 8. 对话实例销毁、插件卸载或宿主关闭

```text
承载本次 Minecraft 游戏的运行实例正在关闭，因此游戏连接和事件监听已经停止。不要尝试恢复任务或自行重新连接。
```

此情形仅作尽力而为的延后投放；宿主已经退出时无法即时生成。

## 9. 看门狗后台任务被取消

```text
看门狗后台任务被停止。由于看门狗与游戏会话强绑定，游戏连接也已一并关闭。不要继续依赖旧会话状态执行操作；如果这不是预期行为，向用户说明情况并询问是否重新连接。
```

## 10. 新连接替换旧连接

同一对话成功切换到另一条 Minecraft 连接时，先结束旧 `gameSessionId`，再为新连接建立新的游戏会话和看门狗。新连接失败则保留原连接和原游戏会话，不投放结束提示词。

```text
【Minecraft 游戏会话已结束】
游戏会话 ID：${gameSessionId}
服务器：${server}
持续时间：${duration}
原因：${reason}

原游戏会话的看门狗、结构化事件队列、场景配置和注意配置均已关闭；机器人已经切换到新的连接，新连接属于新的游戏会话。

原 Minecraft 游戏会话因切换服务器而结束。新服务器使用新的游戏会话 ID；不要把旧会话的在线状态、结构化事件队列、场景或注意配置带入新会话。
```
