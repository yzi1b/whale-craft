# 游戏会话

游戏会话在 AI 调用工具成功连接至一个服务器时建立，彻底断开后关闭。（网络波动等导致的断开连接，可以重连则不结束，直到重连尝试次数耗尽。）

会话具有 ID，为16字符长的hex串。

## 会话持有实例

会话持有最多一个 mineflayer 机器人实例，该实例可能替换，因为重连机制的存在。

会话持有固定一个看门狗实例，不能替换。

## 自动重连

自动重连由会话负责。重连具有固定的等待时间和重试次数。自动重连只发生在网络波动导致的断开连接。服务器关闭、被踢出不在此列。

目前使用1s、3次，后面会改成可配置。

## 会话结束

因被踢出而断开连接、AI主动退出、用户点击退出按钮，会结束会话。结束会话时如 mineflayer 存在且仍在服务器，强制断开。

会话结束后，向助理投放提示词，说明会话结束，以及原因。该投放可打断 LLM 生成、工具调用，投放后触发 LLM 生成。
