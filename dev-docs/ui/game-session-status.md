# 游戏会话状态条

会话标题条原「连接到MC」位置在游戏会话存在时显示状态条，连接按钮同时隐藏；游戏会话关闭后恢复连接按钮。

| 状态 | 圆点 | 文字 |
| --- | --- | --- |
| 正常在线 | 绿色 | 游戏服务器地址 |
| 自动重连（包括正在尝试连接） | 黄色 | 正在重连 |
| 会话存在但连接异常 | 红色 | 连接异常 |

右侧仅显示正方形停止图形，tooltip 为「停止」。点击通过游戏会话管理关闭本局，并立即以 `user-stop` 类型插入游戏会话结束提示词；不直接取消 LLM turn。失败显示错误并保留停止入口。

状态条背景只比宿主 UI 背景略有层次，深色模式下不得使用偏亮浮层。停止区固定为 `28×28` 正方形并占满状态条高度，图形在分隔线与右边界之间严格居中；hover 仅使用轻微红色底，不得整块高亮成实心红色。

状态来源为 `/api/mc/status` 的 `gameSessionId`、`online`、`reconnecting` 和 `connection`，每三秒更新；成功停止后立即切回连接按钮。
